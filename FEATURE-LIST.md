# Downwrite feature list

Every user-facing feature in Downwrite, with the release it first shipped in and the date of that release. Bug fixes and minor enhancements are deliberately left out; the README describes the app as a whole and `docs/changes/` holds the design history of each change.

Rows are ordered by release (oldest first), then by area, so a new feature is appended at the bottom. Release dates are the date of the release tag in the maintainer's local time (UTC+11). Downwrite's first public release was 0.9.0, so everything built before it is listed under 0.9.0.

| Area | Feature | What it does | Release | Released |
| --- | --- | --- | --- | --- |
| Editing | Hidden Markdown syntax | Bold, italic, code, links, headings, quotes and code fences collapse to clean typography and expand again when the caret touches them (Bear-style). The syntax stays in the text, so copy, undo and find keep working. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Editing | CommonMark, GFM and extras | CommonMark and GitHub-flavoured Markdown (tables, task lists, strikethrough, autolinks) plus `==highlight==`, `[^footnotes]`, `$math$` styling and YAML front matter. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Editing | Formatting commands | A Format menu (also in the toolbar) with bold, italic, strikethrough, highlight, inline code, link, headings 1–6, body text, bulleted, numbered and task lists, block quote, code block, horizontal rule, indent and outdent, all with keyboard shortcuts. Applying a format again removes it. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Editing | Smart editing keys | Return continues lists, tasks, numbered lists and quotes (twice to leave); Tab and ⇧Tab indent and outdent; pasting a URL over selected text makes a link. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Editing | Link handling | ⌘-click opens a link; bare URLs are linked automatically; relative file paths resolve against the document; `#heading` links scroll to the heading. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Editing | Find | Find, Find Next, Find Previous and Use Selection for Find through the standard macOS find bar. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Rich blocks | Editable table grid | Tables are drawn as a real grid you type into. Tab and ⇧Tab move between cells (Tab in the last cell adds a row), Return moves down, arrows step across cell edges, ⇧Return adds a line break. Cell Markdown hides its syntax, pasting spreadsheet data fills several cells, and *Edit as Markdown* shows the source. The document text stays plain, aligned GFM. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |

The source collapses while the caret is outside the block; click a diagram to edit it and it re-renders as you type. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Rich blocks | Inline image previews | `![alt](path)` on its own line shows the picture below the collapsed Markdown. Local paths resolve relative to the document; `http(s)` images load from the network. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Rich blocks | Task list checkboxes | `- [ ]` and `- [x]` items are drawn as rounded checkboxes; click one to tick it without moving the caret. The `- [ ] ` source shows while the caret is inside it. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Views | Table of contents sidebar | A right-hand sidebar (⌃⌘O, toolbar button, View menu) listing the headings nested by level, with the section holding the caret highlighted. Click a heading to scroll it to the top and put the caret there. Remembers whether it was left open. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Views | Source view | A per-window toggle (toolbar button, View ▸ Show Markdown Source, ⌘/) that switches to a plain monospaced editor showing every character: no hidden syntax, table grids, diagram cards or checkboxes. Text, caret and undo history carry across. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Views | Word count and reading time | A floating Liquid Glass pill shows the word count and estimated reading time. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Views | Keep on Top | Window ▸ Keep on Top floats the current window above other windows, per window, until turned off. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
| Files | Mac document app | Built on the macOS document system: tabs, Versions, autosave, Open Recent and full undo and redo. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |

| Files | Follows the file on disk | When another app changes the open file and you have no unsaved edits, Downwrite reloads it within about a second (or when you switch back to it), replacing only the changed text so the caret and scroll position stay put. | [v0.9.0](https://github.com/derrickwheals/downwrite/releases/tag/v0.9.0) | 2026-10-09 |
